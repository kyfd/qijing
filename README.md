# 栖境

Windows 本地优先的只读文件观察工具。把你授权的目录画成生态地图：谁占空间、哪里在涨、哪些像闲置或重复，并给出可核对的说明。它不替你删文件。

托盘常驻，点图标打开内嵌地图。默认不联网、不听端口、不改你授权目录里的任何文件。可选接 OpenAI 兼容接口做只读巡视，发出去的是匿名汇总，发送前会让你看一眼。

## 项目定位

不是清理器，也不会自动整理。它只观察、解释，决定留给你：

- 只观察用户逐个授权的目录，不扫描全部磁盘；
- 用规则和可视化解释文件生态状态；
- 给出建议，但不替用户处置文件；
- 默认离线工作，可选 Agent 能力也受匿名数据边界约束；
- 把隐私边界和只读能力作为架构约束，而不是界面选项。

## 只读与隐私承诺

针对用户授权目录，本应用的目标与设计保证如下：

- **永不删除、移动、重命名或写入其中的文件与目录。**
- 扫描默认只访问文件系统元数据，不读取文件正文。
- 只有用户为某个授权目录明确开启“本地哈希”后，扫描器才读取文件字节；字节仅在本地用于计算哈希，不作为正文保存或发送。
- 默认不联网、不开启遥测，也不要求云端模型。
- 授权目录初始为空；应用没有“扫描全部磁盘”的默认权限。
- Agent 目标上只接收匿名标识和聚合特征，不接收真实路径、文件名或文件正文。
- CLI、界面和本地 API 的设计均不提供对授权目录中文件进行修改的能力。

应用自身仍需写入其私有数据目录，用于配置、索引、扫描快照和审计记录；这一写入不针对用户授权目录。撤销授权或重置应用数据只影响应用自己的索引和配置，不触碰源文件。

更完整的数据边界见 [隐私说明](docs/privacy.md)，进程隔离和威胁模型见 [架构说明](docs/architecture.md)。

## 目标功能

以下均为规划中的目标能力，完成状态应以当前版本发布说明和可用命令为准：

- **白名单授权**：按目录逐个授权，并为每个根目录配置排除项和本地哈希开关。
- **只读扫描**：收集类型、大小和时间等元数据，建立本地快照与趋势。
- **生态分类**：识别活跃目录、长期闲置目录、孤儿下载、僵尸项目、重复候选、已解压归档候选、异常增长目录及未备份风险。
- **可解释建议**：每项判断展示依据，仅支持忽略、稍后处理或在资源管理器中定位，由用户自行决定后续操作。
- **生态地图**：以空间、颜色和关系展示目录健康度，并支持搜索、缩放、下钻和时间快照。
- **本地摘要**：规则引擎生成中文观察摘要；无需模型即可使用核心分析。
- **真实 Agent**：支持 OpenAI-compatible 云端或本地模型；最多执行 5 步匿名只读调查，所有 Payload 在发送前展示并要求确认。
- **隐私审计**：展示授权范围、排除项、网络状态、扫描记录和 Agent payload。
- **安静运行**：启动后仅常驻通知区域，点击托盘图标才显示完整生态地图；窗口关闭后继续隐藏运行。

分类结果属于启发式观察，不等于文件无用、已备份或可以安全删除。

## Windows 桌面版

普通用户运行：

```powershell
.\build\windows\ecosystem-desktop.exe
```

程序启动后只常驻 Windows 右下角通知区域，主窗口默认不出现：

- 单击“栖境”托盘图标或选择“显示栖境”打开生态大图；
- 在“设置 → 观察目录”中点击“选择文件夹”，会打开 Windows 原生目录选择器；
- 也可以选择“扫描整台电脑”：应用先列出可用的本地固定磁盘（如 `C:\`、`D:\`），只有再次确认后才批量授权并扫描；
- 整机扫描默认不包含 U 盘、光驱、网络映射盘或离线磁盘；
- 点击窗口关闭按钮只隐藏到托盘；
- 再次启动程序会唤醒已有窗口，不会创建第二个实例；
- 只有托盘菜单“退出”会真正结束程序；
- 桌面版不监听 TCP 端口、不打开外部浏览器。

目标机器需要 Microsoft Edge WebView2 Runtime。Windows 10/11 通常已安装；缺失时需从 Microsoft 官方安装。

### 配置 Agent API

点击托盘图标打开栖境，然后进入“设置 → Agent 模型”：

1. 选择云端模型或本地模型；
2. 填写 OpenAI-compatible Base URL，例如 `https://api.openai.com` 或 `http://127.0.0.1:11434`；
3. 填写模型名称；云端模型还需填写 API Key，本地 Ollama/LM Studio 可以留空；
4. 保存并测试连接；
5. 显式开启模型联网；
6. 点击“让 Agent 巡视”，检查确切匿名 Payload 后确认运行。

API Key 使用 Windows 当前用户 DPAPI 加密，不写入 SQLite。云端 Payload 不包含文件名、路径、哈希、精确大小、精确时间或文件正文。

## 开发 CLI

`cmd/ecosystem` 保留为显式开发预览工具：

```text
ecosystem serve      启动仅监听 127.0.0.1:8765 的本地服务
ecosystem status     查看服务与最近扫描状态
ecosystem open       在浏览器中打开本地界面
ecosystem privacy    查看隐私边界和匿名 Agent payload
```

扫描通过本地界面发起，以使用当前页面的随机会话令牌。另有独立只读工具：

```text
ecosystem-scanner [-hash] ROOT...
```

它只向标准输出返回匿名数据，不包含文件名和路径。CLI 不提供 `delete`、`move`、`rename` 或其他修改授权目录文件的命令。

## 快速开始（开发预览）

### 前置条件

- Windows 10/11 x64
- Go 1.26.3 或满足 `go.mod` 的更高兼容版本
- Microsoft Edge WebView2 Runtime

### 构建桌面版

```powershell
git clone https://github.com/kyfd/qijing.git
cd qijing
go test -tags production ./...
# 仅在替换 internal\appicon\appicon.ico 后重新生成图标资源：
go run .\cmd\icon-resource
go build -tags production -trimpath `
  -ldflags="-H windowsgui -s -w" `
  -o build\windows\ecosystem-desktop.exe `
  .\cmd\ecosystem-desktop
```

`assets\appicon.png` 是品牌图标母版；多尺寸 ICO 同时用于任务栏、窗口标题栏和通知区域。仓库已包含生成后的 amd64 Windows 资源，因此常规构建不依赖外部图标文件。

独立匿名扫描器：

```powershell
go build -o dist\ecosystem-scanner.exe .\cmd\ecosystem-scanner
```

首次进入时没有任何目录权限，可以先点击“演示生态”；只有用户显式添加根目录后才能扫描。开发、测试与 Windows 构建约定见 [开发指南](docs/development.md)。

## 当前界面

当前本地界面包含：

1. **生态地图**：世界、生态区域、目录与文件关系的分层视图；面积表示空间占用，颜色表示健康状态，标记提示需要关注的区域。
2. **详情抽屉**：展示大小、活动时间、增长趋势、分类依据和建议，不展示自动处理按钮。
3. **授权设置**：通过 Windows 原生目录选择器管理文件夹，也可预览并确认本机固定磁盘后执行受预算约束的整机扫描。
4. **扫描状态**：展示进度、错误、取消状态和最近扫描时间。
5. **隐私审计**：明确显示“只读观察模式”“文件修改能力：无”“云端上传：关闭”，并允许查看 Agent 实际 payload。
6. **资源管理器定位**：只负责打开 Windows 资源管理器并选中目标；应用不随后执行删除、移动、重命名或写入。

桌面 UI 通过 Wails 的进程内资源处理器加载，不创建 TCP listener；页面操作仅在当前应用进程内转发到 Go 服务。

## 限制与非目标

- 项目处于早期阶段，架构文档描述的是目标边界，并非全部能力已实现或完成安全验证。
- 应用不会自动清理、整理、归档、恢复或备份文件。
- 应用不会判断某个文件“可以删除”；它只提供观察结果和启发式建议。
- 未开启本地哈希时，无法确认内容完全相同，只能基于元数据给出相似候选。
- 开启本地哈希会读取已授权且未被排除的文件字节，可能增加磁盘 I/O，但读取和计算保持在本地。
- 整机扫描仍受明确授权、排除规则、条目/错误/时间预算和随时取消约束；达到预算时保存标记为不完整的只读快照，不继续无限遍历。
- 云端占位文件、重解析点、无权限路径、隐藏或敏感目录默认跳过，因此统计可能不完整。
- 未备份风险只能依据可见信息推测，不能代替真实备份验证。
- Git 状态、归档对应关系、活动度和增长异常都属于启发式判断，可能产生误报或漏报。
- 系统通知、增量监听和可选模型尚未实现；托盘与完整内嵌大图已可用。
- 目前的只读承诺仍需通过不变性测试、安全测试和发布审计持续验证。
